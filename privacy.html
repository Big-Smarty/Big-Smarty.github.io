BigSmarty Tech Publisher

Privacy Policy

Last updated: 2 November 2026

BigSmarty Tech Publisher ("the app") is a private tool that publishes videos to the YouTube channel @bigsmartytech and reads that channel's analytics. It is used only by the channel owner, on the channel owner's own computer.

Google user data the app accesses

With the channel owner's permission, given on Google's consent screen, the app uses these Google OAuth scopes for the owner's own account only:

  • YouTube management (youtube.force-ssl): to upload the channel's own videos, set their metadata and thumbnails, add them to the channel's own playlists, upload caption tracks and read the videos back.
  • YouTube Analytics and YouTube data, read-only (yt-analytics.readonly, youtube.readonly), including the YouTube Reporting API: to read view counts, watch time, audience retention, impressions and click-through rate for the channel's own videos.

How the data is used

The data is used only to publish and check the channel's own videos and to show the channel owner how those videos perform. It is not used for advertising, not used to train AI or machine-learning models, and not used for any purpose unrelated to running the channel.

Storage and security

OAuth tokens are stored on the channel owner's computer in files that only the owner's user account can read. Analytics reports are saved as local files on the same computer. Nothing is stored on a server run by the app, because there is none.

Sharing

The app does not sell, rent, transfer or disclose Google user data to anyone. Data goes only between the owner's computer and Google's own APIs.

Limited Use

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

Tokens are kept until the owner revokes them. Access can be revoked at any time at myaccount.google.com/permissions; the local token and report files are then deleted from the owner's computer.

Children

The app is not directed at children and does not knowingly process data about children.

Changes and contact

Changes to this policy are published on this page with a new date. Questions: open an issue at github.com/Big-Smarty/Big-Smarty.github.io.
